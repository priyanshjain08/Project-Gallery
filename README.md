# Dynamic Gallery 🖼️

A simple **Dynamic Gallery** built with **HTML and CSS** using Flexbox.

## ✨ Features

- 4-column responsive gallery layout
- Uses CSS Flexbox for column arrangement
- Multiple images displayed in different orders
- Simple and clean HTML/CSS structure

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox

## 📁 Project Structure

```text
Dynamic-Gallery/
├── index.html
├── img1.png
├── img2.png
├── img3.png
└── img4.png
```

## 🚀 How to Run

1. Clone the repository.
2. Make sure all image files are in the same folder as `index.html`.
3. Open `index.html` in your browser.

That's it! 🎉
